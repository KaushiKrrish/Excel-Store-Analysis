# Excel-Store-Data-Analysis
An interactive Excel dashboard project built to analyze Vrinda Store’s annual sales performance and generate actionable business insights using data visualization and reporting techniques.

## Project Overview

This project focuses on analyzing Vrinda Store sales data to understand customer behavior, sales trends, order performance, and channel contribution.
The dashboard was created in Microsoft Excel using pivot tables, charts, slicers, and data cleaning techniques.
The objective was to transform raw sales data into meaningful insights that can help improve sales strategy and customer targeting.

## Tools & Features Used
Microsoft Excel
Pivot Tables
Pivot Charts
Slicers
Data Cleaning
Conditional Formatting
Interactive Dashboard Design

## Key Dashboard Insights
Women customers contribute around 65% of total purchases
Maharashtra, Karnataka, and Uttar Pradesh are the top-performing states
Adult age group (30–49 years) contributes the highest share of orders
Amazon, Flipkart, and Myntra are the major sales channels
Over 90% of orders were successfully delivered

## Dashboard Components
### The dashboard includes:
Orders vs Sales Trend Analysis
Sales by Gender
Order Status Distribution
Top Performing States
Orders by Age & Gender
Orders by Sales Channel
Interactive filters for:
Month
Channel
Product Category

## Business Conclusion
### To improve sales, Vrinda Store should focus marketing campaigns and promotional offers on:
Women customers
Age group 30–49 years
Customers from Maharashtra, Karnataka, and Uttar Pradesh
Major platforms like Amazon, Flipkart, and Myntra
